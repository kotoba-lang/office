kotoba-lang/office

Pure CLJC / EDN runtime for Office Open XML packages. It reads .pptx, .xlsx, and .docx, extracts deterministic graph data, and embeds that graph back as ocz/causal.edn without a JavaScript runtime.

office.opcOOXML zip read/write with raw round-trip preservation.
office.graphPortable EDN graph from document, slide, sheet, and text parts.
office.embedNon-destructive EDN payload embedding.
office.exportEDN, DOT, GraphML, and compact SVG inspection.
(require '[office.opc :as opc]
         '[office.graph :as graph]
         '[office.embed :as embed])

(def pkg (opc/open-package bytes))
(def g (graph/package-graph pkg))
(def out (embed/embed-bytes bytes))
